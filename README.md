# 🧊 G-Creativa 3D Voxel Studio

Un motor de modelado Voxel 3D interactivo y de código abierto, diseñado y programado por [gcreativaa](https://github.com/gcreativaa). 

Construido sobre Python y Ursina Engine, este entorno espacial permite a los artistas digitales y desarrolladores indie esculpir modelos tridimensionales bloque a bloque, utilizando cálculos de vectores normales para la construcción posicional exacta. Es la herramienta puente perfecta entre el Pixel Art 2D y el modelado 3D estructurado.

## 🚀 Características del Motor

*   **Renderizado Espacial en Tiempo Real:** Interfaz de construcción fluida a 60+ FPS.
*   **Construcción por Vectores Normales:** Algoritmo de raycasting que detecta la cara exacta del polígono enfocada para adherir geometría adyacente sin solapamientos.
*   **Cámara Libre (First Person):** Navegación inmersiva en los ejes XYZ (W, A, S, D + Ratón) para inspeccionar el modelo 3D desde cualquier ángulo.
*   **Paleta Dinámica Cyberpunk:** Cambio instantáneo de materiales en memoria mediante atajos de teclado (Teclas 1 al 5).

## 🛠️ Requisitos e Instalación

Este software requiere Python 3.10+ y el motor gráfico Ursina.

1. Clona este repositorio en tu estación de trabajo:
   ```bash
   git clone [https://github.com/gcreativaa/voxel-studio-3d.git](https://github.com/gcreativaa/voxel-studio-3d.git)

Accede al directorio:

Bash
cd voxel-studio-3d
Instala el motor de renderizado 3D:

Bash
pip install ursina
Inicia el entorno virtual:

Bash
python voxel_studio_3d.py
🎮 Controles de la Interfaz
W, A, S, D: Movimiento espacial de la cámara.

Ratón: Rotación de la visión.

Espacio: Saltar / Ascender.

Clic Izquierdo: Instanciar nuevo polígono (Construir).

Clic Derecho: Destruir polígono (Borrar).

Teclas 1-5: Cambiar el material/color del bloque activo.

ESC: Cerrar el motor de forma segura.
